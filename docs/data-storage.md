# 本机数据与空间管理（1.2.0）

程序安装目录只存放程序。默认业务数据位于 `%APPDATA%\DeployCenter`；开发版使用 `DeployCenter-Development`。位置指针独立保存在 `%LOCALAPPDATA%\DeployCenter\Settings`，不会随业务目录迁移。

## 产物占用

同一内容的 JAR 按 SHA-256 只保留一份，多目标共用固定文件。选择和正式部署前的完整 ZIP、Manifest、所有条目 CRC 及哈希校验不变；不会直接上传仍可能被构建覆盖的源文件。内容发布到最终位置前先在本任务临时目录完成复制和校验。

默认在任务全部成功（包括未配置健康检查的成功部署）后清理产物。失败或取消任务保留 7 天，可调整；重试全部失败目标成功后释放原任务引用。多任务共享文件时，仍有任务需要它就保留。

**中断任务始终保留**，不会因超期或人工清理删除。请先核实远端结果、结束中断状态，再按失败任务策略处理。运行中和取消中的任务同样受保护。保留数量和总大小上限是受保护产物之外的清理目标，必要时实际占用可以超过上限。

设置页支持成功后删除、保留最近 N 个不同 JAR、按总占用上限三种策略；修改后需预览并确认，才保存策略和应用。人工清理可以移除仍在失败保留期内的产物，但必须确认受影响任务；不会删除运行、取消中或中断任务的产物。文件被占用或内容异常时保留文件，不改变部署结果。

产物清理后仍保留文件指纹、大小、修改时间、Git 信息、目标结果与步骤耗时。该任务不能直接使用原文件重试，界面会说明原因并提供重新构建或选择现有 JAR 的入口。手动回滚使用远程备份，与本机产物无关。

完整日志独立保存，跟随历史条数/天数清理。历史记录移除后，无剩余任务引用的产物也可回收；共享引用不受影响。完整日志压缩为可选项，本版暂未实现。

## 升级与临时文件

SQLite 结构迁移前自动备份。首次升级会列出旧版产物总占用、成功任务占用，并询问是否清理；未经确认不删除旧版文件。默认建议只清理成功任务，失败和中断任务保留。旧文件元数据缺失、目录异常或指纹不一致时保留并提示。

临时文件按任务分目录。任务成功、失败或取消后清理自己的临时文件；应用启动清理超过 24 小时且不属于活动/中断任务的内容。无法确认归属、链接或被占用的内容保留，之后再处理。

清理只接受数据目录中本工具命名的产物和临时文件；逐层拒绝符号链接、目录联接、`..` 和越界路径，不根据导入配置对任意路径执行删除。

## 更换数据目录

设置中选择空目录，应用先检查可写性、磁盘空间、系统目录和父子关系。迁移前若有可清理内容，会建议先减少占用，也可保持现状直接继续。存在运行、取消或未处理的中断任务时不能迁移。

迁移复制全部内容，再检查文件数量、大小、SHA-256、SQLite 可读性与凭据密文。取消或失败继续使用原目录；只清理本次创建且能确认归属的目标内容。校验完成后重启，启动时再次核对新目录才切换；丢失、损坏或中断迁移会给出恢复选择，不会悄悄创建空配置。

原目录默认保留。核对新目录的配置、历史、日志和加密凭据后，可保留旧副本或输入完整旧路径确认删除；旧副本被修改时拒绝自动删除。

配置导出不包含本地位置指针、完整 JAR、日志文件或凭据；导入配置不会迁移数据目录。跨电脑移动应保留原数据并自行核实 DPAPI 凭据可用性，不能把密文当作可跨用户的密码备份。


旧版快照为避免未经同意删除，首次扫描保持原位置。用户确认后，保护期内的失败副本和所有中断副本继续保留；可整理的重复旧副本会先转移任务引用、校验共享文件，再删除多余物理副本。重试时从主进程读取当前共享路径，不依赖旧界面缓存路径。

新日志的时间与步骤放在独立定位文件，旧日志不伪造缺失信息。默认分批加载 2MB 原文，可继续加载更早内容；点击较早步骤、定位第一处错误时会分批补页，过程可取消。原始完整日志不因此复制或改写。

远程备份来源证明和清理审计独立保存，避免普通历史被清理后把备份来源丢失。未知或待核实清理记录不会触发自动重试删除；需要在备份管理中只读核实。保留 N 仅用于建议选择，默认 0，不在任务结束后静默删除远程文件。


## 1.2.2 的目录选择方式

「设置 → 数据与存储 → 数据位置 → 更换数据目录」选择上级目录，例如 D:\AppData；最终使用 D:\AppData\DeployCenter。向导在检查和确认阶段显示最终绝对路径。最终目录非空、路径链接、越界或空间不足都会拒绝；不会合并或覆盖其他目录。

已经由旧版迁入 D:\AppData 的用户继续使用原位置，不自动改名或搬迁。只有再次主动迁移时才按新规则追加子目录。

进度中的预计剩余时间仅表示当前复制或校验阶段。完成后重启才切换，原目录默认保留；核对新位置后再决定是否删除旧副本，删除仍需输入完整旧目录路径并重新核对内容。
