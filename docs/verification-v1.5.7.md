- 真实 Electron 的 1000×620、1280×800、1600×900 三种窗口及深浅主题，更新说明标题、列表、代码、表格与长路径；无横向溢出，原顶栏/页脚保持可用。

## 隔离安装验收与缓存修复说明

`./scripts/verify-isolated-installer.ps1 -Prepackaged ./release/win-unpacked` 使用独立应用标识、产品名、包名、快捷方式、安装目录与位置记录，执行实际安装、已安装程序启动、覆盖升级、默认保留数据卸载和可选彻底清理。QA 程序使用正式构建的 app.asar 与原生助手，报告记录其指纹。

早期两次 QA 虽隔离了产品标识，但安装框架仍按共同的包名覆盖了用户目录中的框架安装包缓存。发现后先核对该文件确为 QA 包、正式注册仍为 1.5.6，再用本机已验证 SHA-256 的原版 1.5.6 安装器恢复该缓存。恢复记录为 `.test-data/framework-cache-repair.json`。未更改用户配置、历史、凭据或运行中的应用。最终脚本增加独立包名及共享缓存前后指纹检查；正式新版不再产生框架额外缓存。

## 验证边界

- 安装向导本版未逐页手工操作；自动安装验收使用隔离安装和卸载参数，实际执行了安装、启动、升级与卸载。
- 没有手动操作“数据盘丢失”时的 Windows 目录选择器；恢复已有目录和原始记录备份有自动回归。
- 没有对用户当前正式安装进行覆盖升级/卸载，也未连接真实部署服务器。
- 未执行 Linux 上的完整测试套件；WSL 仅用于既有远程 shell 模拟测试。未配置专用非 22 端口 sshd 的集成项明确跳过。
- 系统安装器自身短期解压由 Windows 管理；应用自有持久资料与工作文件跟随配置目录。旧版用户明确选择保留的迁移副本不会静默删除，旧文件被占用、链接或内容冲突则保留并显示提示。
- 1.5.5 及更早版本的交接代码不能通过下载新安装器修复，请正常退出后手动覆盖一次；1.5.6 起采用独立更新助手。
