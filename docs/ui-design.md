# YOTOO 界面设计规范

界面以服务工作台为入口。侧栏切换服务与全局页面，内容区展示当前操作，部署按钮固定在工作台底部。设置使用侧栏分类。任务返回保留来源页面和该页的筛选、搜索及位置。

## 样式变量

- 颜色、间距、形状和排版统一定义在 `src/design/tokens.css`。Tailwind 直接引用同一套变量。
- 布局间距以 4px 为单位。普通控件、面板和对话框的圆角分别为 6、10、14px。胶囊和圆形属于独立形状。
- 普通字重为 400，强调为 600。页面标题用 20px、行高 28px。紧凑和舒适密度共享排版角色，正文、说明和控件随密度变化。
- 普通操作使用 `Button`，通过 `variant` 与 `size` 表达主次及尺寸。复合控件保留原有角色、焦点移动和快捷键语义。
- 优先用即时状态反馈。减少动效时，按钮、提示和侧栏缩短或跳过动画，存储区定位使用即时滚动。

运行 `npm run check:style` 检查布局间距、圆角和字重。桌面验收覆盖最小窗口、1000 × 620，以及 125% 和 150% 缩放下的深浅主题。
